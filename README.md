# Lab1

Лабораторна робота №1 на Python і Tkinter.

## Структура проєкту

- `Lab1.py` — головне вікно, меню та керування переходами `Робота1`.
- `module1.py` — перша сторінка діалогу `Робота1`.
- `module1_page2.py` — друга сторінка діалогу `Робота1`.
- `module2.py` — діалог `Робота2` зі списком груп.

## Робота програми

Пункт `Робота1` відкриває першу сторінку з кнопками `Далі >` і `Відміна`.
Після `Далі >` перша сторінка закривається, а відкривається друга сторінка
з кнопками `< Назад`, `Так` і `Відміна`.

Пункт `Робота2` відкриває список груп факультету. Після вибору групи та
натискання `Так` її назва передається до головного вікна.

## Запуск

У проєкті використано ООП: кожне діалогове вікно реалізоване окремим класом,
а клас `Work1Workflow` керує переходами між сторінками `Робота1`.

Для повної відповідності варіанту потрібно знати номер студента `Ж` у
журналі та реалізувати завдання за формулами `В1 = Ж mod 4` і
`В2 = (Ж + 1) mod 4`.
