# Лабораторні роботи з ООП

## Lab2 — графічний редактор об'єктів

`Lab2.py` реалізує варіант для студента з номером у журналі `Ж = 10`.
Програма використовує абстрактний клас `Shape`, поліморфні класи `Dot`,
`Line`, `Rectangle` та `Ellipse`, а також статичний масив вказівників
місткістю `Ж + 100 = 110` об'єктів.

Параметри варіанта:

- меню `Файл`, `Об'єкти`, `Довідка`, причому поточний тип позначається в меню
  `Об'єкти`;
- «гумовий» слід — суцільна синя лінія;
- прямокутник вводиться двома протилежними кутами та відображається з
  чорним контуром і білим заповненням;
- еліпс вводиться від центра до кута охоплюючого прямокутника та
  відображається без заповнення.

Запуск:
Клацніть і перетягніть вказівник миші на полотні для лінії, прямокутника
або еліпса. Крапка створюється одним клацанням. Під час введення
відображається синій «гумовий» слід.

## Lab1

Лабораторна робота №1 на Python і Tkinter.

## Структура проєкту

- `Lab1.py` — головне вікно, меню та керування переходами `Робота1`.
- `module1.py` — перша сторінка діалогу `Робота1`.
- `module1_page2.py` — друга сторінка діалогу `Робота1`.
- `module2.py` — діалог `Робота2` зі списком груп.

## Робота програми

Пункт `Робота1` відкриває першу сторінку з кнопками `Далі >` і `Відміна`.
Після `Далі >` перша сторінка закривається, а відкривається друга сторінка
з кнопками `< Назад`, `Так` і `Відміна`.

Пункт `Робота2` відкриває список груп факультету. Після вибору групи та
натискання `Так` її назва передається до головного вікна.

## Запуск

У проєкті використано ООП: кожне діалогове вікно реалізоване окремим класом,
а клас `Work1Workflow` керує переходами між сторінками `Робота1`.

Для повної відповідності варіанту потрібно знати номер студента `Ж` у
журналі та реалізувати завдання за формулами `В1 = Ж mod 4` і
`В2 = (Ж + 1) mod 4`.
