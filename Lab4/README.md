# Lab4 — графічний редактор об'єктів

Лабораторна робота реалізує варіант 10. Оскільки номер парний, об'єкт
`MyEditor` створюється динамічно у функції `main`, а після завершення
роботи гарантовано знищується у блоці `finally`. Сховище має місткість
`Ж + 100 = 110` об'єктів.

## Реалізовані типи

- крапка;
- лінія;
- прямокутник;
- еліпс;
- лінія з кружечками;
- каркас куба.

Усі форми наслідують абстрактний `Shape` і реалізують `show`. Класи
`LineWithCircles` та `WireframeCube` використовують множинне успадкування.
Під час введення всі форми мають синій пунктирний «гумовий» слід.
Кожна форма має кнопку Toolbar з підказкою.

## Запуск
